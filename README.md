# Ping-Pong  🏓

Um jogo clássico de Ping-Pong desenvolvido em Python utilizando a biblioteca **Pygame**. 

## 🎮 Sobre o Jogo

Este é um jogo multiplayer local para dois jogadores. O objetivo é fazer com que a bola passe pela raquete do adversário. O primeiro jogador a alcançar **10 pontos** vence a partida!

### Funcionalidades:
- Multiplayer local (2 jogadores no mesmo teclado).
- Sistema de colisão dinâmico: a bola muda sua trajetória dependendo da parte da raquete onde bate.
- Tela de fim de jogo informando o vencedor.
- Opção para reiniciar a partida facilmente após o fim de jogo.

## ⚙️ Pré-requisitos

Para rodar este jogo, você precisará do Python instalado na sua máquina, além da biblioteca `pygame`.

1. Instale o Python (versão 3.x recomendada).
2. Instale o Pygame usando o pip:
   ```bash
   pip install pygame
   ```

## 🚀 Como Jogar

1. Salve o código do jogo em um arquivo (por exemplo, `main.py`).
2. Abra o terminal na pasta onde o arquivo foi salvo.
3. Execute o comando:
   ```bash
   python main.py
   ```

## 🕹️ Controles

| Ação | Jogador 1 (Esquerda) | Jogador 2 (Direita) |
| :--- | :---: | :---: |
| **Mover para Cima** | `W` | `Seta para Cima` (⬆️) |
| **Mover para Baixo** | `S` | `Seta para Baixo` (⬇️) |

**Outros Comandos:**
- **Reiniciar o jogo:** Pressione `R` na tela de "Fim de Jogo".
- **Sair do jogo:** Feche a janela.
